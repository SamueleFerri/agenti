# 6 – Probabilistic Logic Programming

Probability inside a logic program: the distribution semantics, and inference
over it with `cplint`.

## Classes

| class | deck | what is in it |
|---|---|---|
| [`l9`](l9/) | *L9 – Reasoning Under Uncertainty in Prolog* | worlds and their probabilities; LPADs; explanations that overlap, and BDDs; a Bayesian network as a program; deciding under uncertainty |

## What you need

**A browser, and nothing else.** The programs run at
[cplint.eu](https://cplint.eu), a SWISH front-end with `cplint` already loaded:
paste a program into the left-hand pane, ask goals in the box at the bottom right.

**Not the 2P-Kt web IDE, and not plain SWISH**: neither has `cplint`.
